# 促销活动基础数据

- **计划 ID：** EC-014
- **所属阶段：** 第2周
- **优先级：** P1
- **依赖：** EC-010
- **状态：** 未开始

## 1. 目标与用户价值

为销量变化和定价分析提供促销背景。

## 2. 功能范围

### 本次包含
- 促销活动基本信息、商品关联、起止时间、折扣和状态。
- 只读查询接口。

### 本次不包含
- 不重建现有 FastAPI、Agent、RAG、SSE、Checkpointer、Milvus 或前端基础设施。
- 不实现本文件未列出的相邻业务功能。

## 3. 现有能力复用与代码检查

复用商品、时间字段、API 鉴权。

Codex 必须先检查当前仓库真实代码、模型、路由、迁移和测试；不得凭计划臆造文件路径或重复造轮子。

## 4. 数据与接口

promotions 模型和按商品/时间查询 Service。

## 5. 业务规则与边界条件

促销时间区间采用明确闭开规则；多活动叠加需标记，不擅自推算最终成交价。

## 6. 安全、权限与隐私

ownership 校验；折扣范围校验；不允许此功能直接发布促销。

## 7. 人工审核 / 人工介入

本功能仅存储/查询活动数据；真实发布促销必须走第5周审批闭环。

## 8. 异常与恢复

重叠促销、跨时区、过期活动、缺少关联商品。

## 9. 测试要求

时间边界、折扣范围、跨租户和只读接口测试。

## 10. 验收标准

Agent 可查询某商品在指定时间段的促销背景；无发布能力。

## 11. Codex 执行约束

1. 先只读检查并汇报现状、差异、拟修改文件和风险。
2. 等待确认后，仅实施本计划范围。
3. 先补测试，再实现或同步实现；不得删除已有测试来通过检查。
4. 不得修改自动生成的 OpenAPI SDK 文件；如 API schema 变化，按项目既定流程重新生成。
5. 汇报实际修改文件、迁移、测试命令和真实测试结果。
