# 销售与商品表现 API

- **计划 ID：** EC-017
- **所属阶段：** 第2周
- **优先级：** P1
- **依赖：** EC-015, EC-016
- **状态：** 未开始

## 1. 目标与用户价值

向前端提供商品表现、销售趋势和异常候选数据。

## 2. 功能范围

### 本次包含
- 商品销售趋势、Top/Bottom 商品、指标摘要。
- 明确排序、分页和时间范围。

### 本次不包含
- 不重建现有 FastAPI、Agent、RAG、SSE、Checkpointer、Milvus 或前端基础设施。
- 不实现本文件未列出的相邻业务功能。

## 3. 现有能力复用与代码检查

复用销售 Service，不在 Router 重复写统计 SQL。

Codex 必须先检查当前仓库真实代码、模型、路由、迁移和测试；不得凭计划臆造文件路径或重复造轮子。

## 4. 数据与接口

只读聚合 API 和 OpenAPI schema。

## 5. 业务规则与边界条件

Top/Bottom 只基于有效数据；数据不足时返回空/不足提示，不编造排名。

## 6. 安全、权限与隐私

ownership、最大跨度、结果上限和响应字段最小化。

## 7. 人工审核 / 人工介入

本功能不触发外部写操作。

## 8. 异常与恢复

同值排序稳定、空数据、极端日期范围。

## 9. 测试要求

API 集成测试、跨租户测试、统计值回归测试。

## 10. 验收标准

前端能稳定获取经营摘要和趋势数据，结果与 Service 一致。

## 11. Codex 执行约束

1. 先只读检查并汇报现状、差异、拟修改文件和风险。
2. 等待确认后，仅实施本计划范围。
3. 先补测试，再实现或同步实现；不得删除已有测试来通过检查。
4. 不得修改自动生成的 OpenAPI SDK 文件；如 API schema 变化，按项目既定流程重新生成。
5. 汇报实际修改文件、迁移、测试命令和真实测试结果。
