# 电商只读业务查询 Services

- **计划 ID：** EC-031
- **所属阶段：** 第4周
- **优先级：** P0
- **依赖：** EC-010, EC-015, EC-021, EC-027
- **状态：** 未开始

## 1. 目标与用户价值

提供 Agent 和 API 共用的只读业务查询能力。

## 2. 功能范围

### 本次包含
- 商品、销售、流量（数据集支持时）、库存、促销、竞品和快照查询。
- 统一时间范围和分页参数。

### 本次不包含
- 不重建现有 FastAPI、Agent、RAG、SSE、Checkpointer、Milvus 或前端基础设施。
- 不实现本文件未列出的相邻业务功能。

## 3. 现有能力复用与代码检查

复用现有 SQLModel Service/Repository 风格。

Codex 必须先检查当前仓库真实代码、模型、路由、迁移和测试；不得凭计划臆造文件路径或重复造轮子。

## 4. 数据与接口

只读 Service 接口和测试。

## 5. 业务规则与边界条件

禁止任意 SQL；默认最大时间跨度和结果数量；无数据返回明确空结果。

## 6. 安全、权限与隐私

Service 内强制 ownership；Tool 调用身份从可信上下文注入，不接受模型伪造 tenant_id。

## 7. 人工审核 / 人工介入

本功能只读，不触发审批。

## 8. 异常与恢复

数据库超时、无权限、数据缺失、结果过大。

## 9. 测试要求

Service 单测、权限测试、查询性能与边界测试。

## 10. 验收标准

所有查询可由 API/Agent 安全复用，返回稳定结构。

## 11. Codex 执行约束

1. 先只读检查并汇报现状、差异、拟修改文件和风险。
2. 等待确认后，仅实施本计划范围。
3. 先补测试，再实现或同步实现；不得删除已有测试来通过检查。
4. 不得修改自动生成的 OpenAPI SDK 文件；如 API schema 变化，按项目既定流程重新生成。
5. 汇报实际修改文件、迁移、测试命令和真实测试结果。
