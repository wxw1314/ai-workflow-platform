## 1. 目标与用户价值

将现有 Agent 改造成可规划、执行、验证和总结经营问题的单 Agent 流程。

## 2. 功能范围

### 本次包含
- 意图理解与必要澄清。
- 规划并调用只读 Tools/RAG。
- 确定性计算。
- 证据验证。
- 生成报告或说明证据不足。

### 本次不包含
- 不重建现有 FastAPI、Agent、RAG、SSE、Checkpointer、Milvus 或前端基础设施。
- 不实现本文件未列出的相邻业务功能。

## 3. 现有能力复用与代码检查

复用现有 LangGraph graph、ToolNode、checkpointer、stream 和取消机制。
