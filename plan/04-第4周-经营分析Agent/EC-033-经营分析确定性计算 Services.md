# 经营分析确定性计算 Services

- **计划 ID：** EC-033
- **所属阶段：** 第4周
- **优先级：** P0
- **依赖：** EC-015, EC-027, EC-030
- **状态：** 未开始

## 1. 目标与用户价值

将销量变化、转化变化、价差和异常检测交给代码计算。

## 2. 功能范围

### 本次包含
- calculate_sales_change。
- calculate_conversion_change（数据支持时）。
- calculate_price_gap。
- detect_sales_anomalies。
- build_evidence_bundle。

### 本次不包含
- 不重建现有 FastAPI、Agent、RAG、SSE、Checkpointer、Milvus 或前端基础设施。
- 不实现本文件未列出的相邻业务功能。

## 3. 现有能力复用与代码检查

复用现有数据查询结果，不在 LLM 中做关键算术。

Codex 必须先检查当前仓库真实代码、模型、路由、迁移和测试；不得凭计划臆造文件路径或重复造轮子。

## 4. 数据与接口

纯 Python Service 和单元测试。

## 5. 业务规则与边界条件

缺失数据不视为 0；基期为 0 不输出无穷；阈值需配置且有解释；异常只是候选而非因果结论。

## 6. 安全、权限与隐私

限制输入规模；避免把其他租户聚合数据带入计算。

## 7. 人工审核 / 人工介入

本功能不触发外部写操作。

## 8. 异常与恢复

小样本、极端值、数据断档、重复指标、单位不一致。

## 9. 测试要求

边界值、属性/表驱动测试、与人工计算对照。

## 10. 验收标准

关键数字稳定可复算，异常解释包含阈值和数据覆盖情况。

## 11. Codex 执行约束

1. 先只读检查并汇报现状、差异、拟修改文件和风险。
2. 等待确认后，仅实施本计划范围。
3. 先补测试，再实现或同步实现；不得删除已有测试来通过检查。
4. 不得修改自动生成的 OpenAPI SDK 文件；如 API schema 变化，按项目既定流程重新生成。
5. 汇报实际修改文件、迁移、测试命令和真实测试结果。
