- **计划 ID：** EC-050
- **所属阶段：** 第6周
- **优先级：** P1
- **依赖：** EC-017, EC-036, EC-045
- **状态：** 未开始

## 1. 目标与用户价值

提供项目首页，快速展示经营状态和分析入口。

## 2. 功能范围

### 本次包含
- 指标卡、销售趋势、商品表现、告警摘要、Agent 入口。
- 标明 demo 数据和数据更新时间。

### 本次不包含
- 不重建现有 FastAPI、Agent、RAG、SSE、Checkpointer、Milvus 或前端基础设施。
- 不实现本文件未列出的相邻业务功能。

## 3. 现有能力复用与代码检查

复用 React、TanStack Query、Shadcn UI 和现有布局/鉴权。

Codex 必须先检查当前仓库真实代码、模型、路由、迁移和测试；不得凭计划臆造文件路径或重复造轮子。

## 4. 数据与接口

前端页面和只读 API 集成。

## 5. 业务规则与边界条件

无数据/加载/错误状态完整；指标口径与后端一致；不在前端自行推算关键指标。

## 6. 安全、权限与隐私

按 API 权限渲染；前端不保存服务端密钥；避免 XSS；路由受保护。

## 7. 人工审核 / 人工介入

工作台只读，不提供直接调价或发布促销按钮。

## 8. 异常与恢复

API 慢、部分卡片失败、空数据和窄屏布局。

## 9. 测试要求

组件测试、权限显示、错误状态和接口集成测试。

## 10. 验收标准

用户能看懂当前经营概况并进入对应业务页面。

## 11. Codex 执行约束

1. 先只读检查并汇报现状、差异、拟修改文件和风险。
2. 等待确认后，仅实施本计划范围。

4. 不得修改自动生成的 OpenAPI SDK 文件；如 API schema 变化，按项目既定流程重新生成。
5. 汇报实际修改文件、迁移、测试命令和真实测试结果。
