# 任务、告警与知识库页面整合

- **计划 ID：** EC-055
- **所属阶段：** 第6周
- **优先级：** P2
- **依赖：** EC-034, EC-044, EC-045
- **状态：** 未开始

## 1. 目标与用户价值

将已有知识库与新监控能力整合到统一导航。

## 2. 功能范围

### 本次包含
- 知识库经营分类入口。
- 监控任务启停和运行记录。
- 告警列表、详情和处理状态。

### 本次不包含
- 不重建现有 FastAPI、Agent、RAG、SSE、Checkpointer、Milvus 或前端基础设施。
- 不实现本文件未列出的相邻业务功能。

## 3. 现有能力复用与代码检查

复用现有 KnowledgeBase 页面和组件，不重做 RAG。

Codex 必须先检查当前仓库真实代码、模型、路由、迁移和测试；不得凭计划臆造文件路径或重复造轮子。

## 4. 数据与接口

页面导航与 API 集成。

## 5. 业务规则与边界条件

知识库内容仍是参考材料；任务状态以后端为准；告警处理不自动执行外部动作。

## 6. 安全、权限与隐私

每个资源按 ownership；危险操作二次确认；文档渲染防 XSS。

## 7. 人工审核 / 人工介入

告警处理与任务启停不等于批准调价；写操作仍需独立审批。

## 8. 异常与恢复

后台任务状态延迟、空知识库、权限变化。

## 9. 测试要求

路由权限、资源隔离、任务状态和文档渲染测试。

## 10. 验收标准

核心页面可访问，知识库旧功能无回归，任务/告警状态准确。

## 11. Codex 执行约束

1. 先只读检查并汇报现状、差异、拟修改文件和风险。
2. 等待确认后，仅实施本计划范围。
3. 先补测试，再实现或同步实现；不得删除已有测试来通过检查。
4. 不得修改自动生成的 OpenAPI SDK 文件；如 API schema 变化，按项目既定流程重新生成。
5. 汇报实际修改文件、迁移、测试命令和真实测试结果。
