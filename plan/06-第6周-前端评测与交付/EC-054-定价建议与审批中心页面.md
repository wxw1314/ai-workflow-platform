# 定价建议与审批中心页面

- **计划 ID：** EC-054
- **所属阶段：** 第6周
- **优先级：** P0
- **依赖：** EC-040, EC-041, EC-042, EC-043
- **状态：** 未开始

## 1. 目标与用户价值

展示定价方案差异，并提供安全的人工审批入口。

## 2. 功能范围

### 本次包含
- 方案比较、毛利底线、假设和风险展示。
- 待审批列表、详情、批准/拒绝、执行状态和审计记录。

### 本次不包含
- 不重建现有 FastAPI、Agent、RAG、SSE、Checkpointer、Milvus 或前端基础设施。
- 不实现本文件未列出的相邻业务功能。

## 3. 现有能力复用与代码检查

复用审批 API、现有 UI 组件和用户角色信息。

Codex 必须先检查当前仓库真实代码、模型、路由、迁移和测试；不得凭计划臆造文件路径或重复造轮子。

## 4. 数据与接口

审批页面和状态刷新。

## 5. 业务规则与边界条件

批准前展示 payload 对应的变更前后值、目标、影响、数据时间戳、过期时间；审批后状态不可由前端伪造。

## 6. 安全、权限与隐私

服务端再次校验角色、ownership、状态和 hash；防重复点击；拒绝理由校验。

## 7. 人工审核 / 人工介入

必须人工点击批准；禁止自动批准、模型代批和前端直连 Adapter。

## 8. 异常与恢复

并发审批、过期、重复提交、状态刷新延迟。

## 9. 测试要求

越权、自批、过期、重复点击和审批状态机 UI/API 联合测试。

## 10. 验收标准

审批人可看清风险并完成审批；只有服务端批准状态能触发执行。

## 11. Codex 执行约束

1. 先只读检查并汇报现状、差异、拟修改文件和风险。
2. 等待确认后，仅实施本计划范围。
3. 先补测试，再实现或同步实现；不得删除已有测试来通过检查。
4. 不得修改自动生成的 OpenAPI SDK 文件；如 API schema 变化，按项目既定流程重新生成。
5. 汇报实际修改文件、迁移、测试命令和真实测试结果。
