# 第一种合法数据 Adapter

- **计划 ID：** EC-025
- **所属阶段：** 第3周
- **优先级：** P1
- **依赖：** EC-024
- **状态：** 未开始

## 1. 目标与用户价值

接入一种合法且可持续使用的数据来源，或以 CSV Adapter 作为首个实现。

## 2. 功能范围

### 本次包含
- 首选用户提供 CSV 或官方/授权 API。
- 记录来源标识、授权说明、采集时间和原始字段映射。
- 不做通用爬虫。

### 本次不包含
- 不重建现有 FastAPI、Agent、RAG、SSE、Checkpointer、Milvus 或前端基础设施。
- 不实现本文件未列出的相邻业务功能。

## 3. 现有能力复用与代码检查

复用 Provider 接口和 CSV 导入能力。

Codex 必须先检查当前仓库真实代码、模型、路由、迁移和测试；不得凭计划臆造文件路径或重复造轮子。

## 4. 数据与接口

一个可运行 Adapter 和使用说明。

## 5. 业务规则与边界条件

若 API 权限/配额不可得，退回 CSV，不把页面抓取伪装成稳定 API。

## 6. 安全、权限与隐私

遵守 ToS、robots 和法律；不绕过登录、验证码、付费墙、反爬；凭据不进日志。

## 7. 人工审核 / 人工介入

只采集公开/授权数据，不发布或修改第三方平台内容。

## 8. 异常与恢复

API 变更、配额耗尽、授权撤销、字段缺失。

## 9. 测试要求

Mock 契约测试、真实数据脱敏样本测试、限流和失败恢复测试。

## 10. 验收标准

能从明确合法来源生成标准快照；无法合法接入时 CSV 路径可完成演示。

## 11. Codex 执行约束

1. 先只读检查并汇报现状、差异、拟修改文件和风险。
2. 等待确认后，仅实施本计划范围。
3. 先补测试，再实现或同步实现；不得删除已有测试来通过检查。
4. 不得修改自动生成的 OpenAPI SDK 文件；如 API schema 变化，按项目既定流程重新生成。
5. 汇报实际修改文件、迁移、测试命令和真实测试结果。
