# 竞品与竞品商品关联模型

- **计划 ID：** EC-020
- **所属阶段：** 第3周
- **优先级：** P0
- **依赖：** EC-003, EC-004
- **状态：** 未开始

## 1. 目标与用户价值

维护竞品主体、竞品商品及其与自有商品的映射关系。

## 2. 功能范围

### 本次包含
- competitors、competitor_products。
- 记录平台、商品标识、展示名称、商品 URL（仅作来源元数据）和关联自有商品。
- CRUD 与关联管理。

### 本次不包含
- 不重建现有 FastAPI、Agent、RAG、SSE、Checkpointer、Milvus 或前端基础设施。
- 不实现本文件未列出的相邻业务功能。

## 3. 现有能力复用与代码检查

复用商品模型、ownership、SQLModel CRUD 模式。

Codex 必须先检查当前仓库真实代码、模型、路由、迁移和测试；不得凭计划臆造文件路径或重复造轮子。

## 4. 数据与接口

竞品模型、关联 API 和索引。

## 5. 业务规则与边界条件

一个竞品商品可关联多个自有商品的规则需明确；关联是分析映射，不代表两者完全同质。

## 6. 安全、权限与隐私

用户提交 URL 仅保存/校验格式，不因保存 URL 自动抓取；防 XSS；租户隔离。

## 7. 人工审核 / 人工介入

本功能不触发外部写操作。

## 8. 异常与恢复

重复映射、商品下架、竞品实体合并、URL 变更。

## 9. 测试要求

跨租户、重复关联、删除/停用和 URL 输入测试。

## 10. 验收标准

可维护竞品及关联关系，关联状态可追溯。

5. 汇报实际修改文件、迁移、测试命令和真实测试结果。
